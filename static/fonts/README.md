# Site Mono

Web subset of **Iosevka Term** (Regular, Italic, Bold), Latin plus punctuation,
arrows, box-drawing, geometric shapes and miscellaneous symbols. Iosevka is
licensed under the SIL Open Font License 1.1 with a Reserved Font Name, so this
modified version is renamed "Site Mono". License: `LICENSE-Iosevka.md`.

Regenerate from a locally installed Iosevka with fontTools (`subset` + rename the
`name` table); `assets/css/main.css` is the only user.
